# NestChat

Локальный realtime-мессенджер на NestJS, React и TypeScript. Поддерживает личные диалоги, поиск по username, текстовые сообщения, ответы, редактирование, удаление, статусы прочтения/доставки, presence, typing и защищённые локальные вложения.

## Стек

- Node.js 24 LTS и npm 12
- NestJS, Socket.IO, Prisma ORM, PostgreSQL
- React, Vite, TanStack Query, Zustand, Radix UI
- Vitest, Testing Library, Supertest

## Быстрый запуск для разработки

1. Скопируйте `.env.example` в `.env`. Значения по умолчанию рассчитаны на локальную среду.
2. Запустите PostgreSQL:

   ```powershell
   docker compose up -d db
   ```

3. Установите зависимости и примените миграции:

   ```powershell
   npm install
   npm run db:generate
   npm run db:migrate
   ```

4. Запустите frontend и API:

   ```powershell
   npm run dev
   ```

Откройте `http://localhost:5173`. API и Socket.IO работают на `http://localhost:3000`.

## Полный запуск в Docker

```powershell
docker compose up --build
```

PostgreSQL сохраняется в Docker volume. Загруженные файлы сохраняются в
`apps/api/uploads`, который используется и локальным API, и контейнером.

## Структура

- `apps/api` — NestJS REST API, Socket.IO gateway, Prisma и локальное файловое хранилище.
- `apps/web` — адаптивное React SPA.
- `packages/contracts` — общие Zod-схемы и TypeScript-типы.

## API сообщений

Объект сообщения содержит `replyToId` и `replyTo` с кратким превью исходного сообщения: идентификатором, автором, текстом и признаком удаления. Это позволяет показывать ответы без отдельного запроса к исходному сообщению.

`GET /api/files/:id` возвращает `404`, если запись вложения существует, но физический файл отсутствует в локальном хранилище.

## API аватаров

`POST /api/files/avatar` принимает авторизованный multipart-запрос с полем `avatar`,
сохраняет или заменяет аватар текущего пользователя и возвращает обновлённый `UserDto`.
Поддерживаются JPEG, PNG, WebP и GIF размером до 5 МБ. Веб-клиент перед загрузкой
обрезает изображение до квадрата 512×512 пикселей.

`GET /api/files/avatar/:userId` публично возвращает актуальное изображение аватара.
Адрес из `avatarUrl` содержит версию файла, поэтому заменённый аватар не остаётся в кеше браузера.

## API удаления диалога

`DELETE /api/conversations/:id` скрывает диалог и очищает его текущую историю только для
авторизованного участника. У второго участника переписка сохраняется. Если после удаления
появится новое сообщение или пользователь снова начнёт чат, диалог вернётся в список, но
сообщения, отправленные до удаления, для удалившего пользователя не показываются.

## Ограничения MVP

В первой версии нет групп, каналов, звонков, push-уведомлений, OAuth, восстановления пароля, тёмной темы и end-to-end encryption. Вложения хранятся локально и доступны только участникам соответствующего диалога.
